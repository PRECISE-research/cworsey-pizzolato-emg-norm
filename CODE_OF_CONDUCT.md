# Code of conduct

## Our standard

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: participate in issues, pull requests, and discussions with the same
professional courtesy expected in academic peer review. Critique the method, the
code, and the evidence rather than the person. Assume that a question asked in
good faith deserves an answer in good faith.

## Research-specific expectations

Because this repository distributes human-derived data, two further
expectations apply to everyone taking part:

- Do not post participant-level speculation, reidentification attempts, or any
  content that attempts to link the published opaque labels to real people.
- Raise disagreements about scientific choices — trial roles, reference maxima,
  channel exclusions — as reasoned technical arguments with evidence, as
  described in [CONTRIBUTING.md](CONTRIBUTING.md).

## Reporting

Report unacceptable behaviour to the repository maintainers. Reports are handled
confidentially. Maintainers may remove comments, commits, issues, and pull
requests that breach this code, and may block repeat offenders.
