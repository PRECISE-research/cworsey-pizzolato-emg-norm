# Validation summary

The published model was evaluated with fixed C01-C07
leave-one-participant-out cross-validation. `E01` was reserved for
separate task-generalisation assessment.

## Cycling

- 17 primary conditions.
- Mean condition-level cycle absolute peak error: **6.214%**.
- Participant-level BCa 95% CI: **4.536-8.270%**.
- Mean signed peak error: **+0.233%**.

## External tasks

- Walking, running, bodyweight squatting, and countermovement jumping.
- Mean task-level absolute peak error: **11.900%**.
- BCa 95% CI: **8.402-14.358%**.
- Mean signed peak error: **-7.070%**.

These retained headline values assess agreement with the study-specific
conventional reference normalisation, not an independent physiological gold
standard. The model-rebuild command exports fold-level window metrics for an
bundled cohort feature table.
